# Security Policy

## Project status

This is an intentionally vulnerable educational lab. Known insecure behavior is part of the exercise and is documented at a high level in [VULNERABILITIES.md](./VULNERABILITIES.md). The project is not intended for production use and must not be exposed to the internet or used with real data or credentials.

## Reporting an unintended issue

Please do not publish sensitive details of an unintended issue in a public issue or pull request. If GitHub private vulnerability reporting is enabled for this repository, use it. Otherwise, open a brief public issue asking the maintainer for a private reporting channel without including technical details.

There is no security support or response-time guarantee for this portfolio project. Do not test systems or services outside this repository unless you have explicit authorization.
